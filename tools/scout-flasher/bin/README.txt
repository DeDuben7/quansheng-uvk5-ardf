K5TOOL.exe - bundled, unmodified
================================

Program : K5TOOL v1.8.0.0 (.NET Framework 4.0 console app; runs on the
          .NET Framework 4.8 built into Windows 10/11)
Author  : qrp73
Source  : https://github.com/qrp73/K5TOOL
Licence : GNU General Public License v3.0 (full text: K5TOOL-LICENSE.txt)

ScoutFlasher uses it only to flash UV-K5 V1 radios (bootloader 2.x):

    K5TOOL.exe -port COMx -wrflash firmware_uvk5_v1.packed.bin

It is run as a separate program; ScoutFlasher's own code is not derived
from it. The source code of this version is available at the URL above.
